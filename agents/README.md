# agents

JVMTI-агенты на C++. Каждый агент собирается в отдельную `.so` и подключается к уже запущенному VaultNotes снаружи, через `adb shell cmd activity attach-agent`. Приложение об агенте ничего не знает.

| Каталог | Часть | Что делает |
|---|---|---|
| [`common`](common) | 2–4 | общий каркас: RAII-обёртки для памяти JVMTI и JNI-ссылок, логирование, разбор опций, JSON-отчёт |
| [`part1-recon`](part1-recon) | 1 | разведка: какие классы и откуда загружены, какие native-методы в каких библиотеках |
| [`part2-memory`](part2-memory) | 2 | обход кучи, детекторы секретов, поиск владельца через `FollowReferences`, taint-lite |
| [`part3-behavior`](part3-behavior) | 3 | точки останова на API фреймворка, атрибуция по стеку, правила в JSON |
| [`part4-hidden`](part4-hidden) | 4 | дамп DEX из `ClassFileLoadHook`, перехват native-секретов, `ForceEarlyReturn` |

## Ограничения

- Только debuggable-приложения.
- Часть capabilities включает деоптимизацию: под агентом приложение работает медленнее.
- Агент — инструмент разработчика и аудитора. В release-сборку он попадать не должен.
