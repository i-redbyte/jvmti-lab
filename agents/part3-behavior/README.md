# part3-behavior

Агент части 3: поведенческий аудит (флаги 5–9, 13, 14).

- `SetBreakpoint` на методы фреймворка и чтение аргументов через `GetLocalVariable*`.
- Атрибуция по `GetStackTrace`: первый кадр не из фреймворка.
- Хуки на криптографию, сеть, WebView, Intent и SQLite.
- Хуки описываются JSON-правилами, чтобы расширять аудит без C++.
