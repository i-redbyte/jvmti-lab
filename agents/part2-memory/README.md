# part2-memory

Агент части 2: ищем секреты в памяти (флаги 1–4).

- `IterateThroughHeap` по строкам и примитивным массивам.
- Детекторы: JWT, Bearer-токены, ключи API, PEM, номера карт (проверка Луна), email и телефоны, высокоэнтропийные строки.
- `SetTag` + `FollowReferences` до GC root: кто держит найденный секрет.
- Taint-lite: тег на объекте-ответе сервера и точка останова на `Log.*`.
