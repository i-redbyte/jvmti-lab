# scripts

| Скрипт | Что делает |
|---|---|
| `build-agents.sh [abi]` | собирает все агенты через CMake и NDK; ABI по умолчанию берётся с подключённого устройства |
| `attach-agent.sh [--start] <agent.so> [опции]` | копирует `.so` агента в каталог приложения и подключает агент к процессу (или перезапускает приложение с агентом) |
| `pull-report.sh` | забирает отчёты агента с устройства в `out/` |
| `run-server.sh` | запускает локальный сервер VaultNotes (появится позже) |

Пакет приложения по умолчанию `dev.redbyte.vaultnotes`, его можно переопределить переменной `PKG`. Если подключено несколько устройств, выберите нужное через `ANDROID_SERIAL`.
