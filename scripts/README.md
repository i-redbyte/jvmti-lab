# scripts

| Скрипт | Что делает |
|---|---|
| `attach-agent.sh` | копирует `.so` агента в каталог приложения и подключает агент к запущенному процессу |
| `pull-report.sh` | забирает JSON-отчёт агента с устройства в `out/` |
| `run-server.sh` | запускает локальный сервер VaultNotes |

Пакет приложения по умолчанию `dev.redbyte.vaultnotes`, его можно переопределить переменной `PKG`.
