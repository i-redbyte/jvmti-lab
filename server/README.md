# server

Локальный тестовый сервер VaultNotes на Ktor. Запускается на ноутбуке одной командой, эмулятор ходит на него по адресу `10.0.2.2`.

## Эндпоинты (план)

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/auth/login` | вход, выдаёт токен сессии |
| `POST` | `/auth/logout` | выход |
| `GET`, `POST` | `/notes` | заметки пользователя |
| `POST` | `/payments` | «оплата» премиума |
| `GET` | `/premium/status` | проверка премиума |
| `GET` | `/premium/module` | премиум-модуль |

## TLS

Сервер работает с самоподписанным сертификатом. Он генерируется скриптом при первом запуске и в репозиторий не коммитится.

## Запуск

```bash
./scripts/run-server.sh
```

Проект Gradle появится вместе с первой статьёй.
