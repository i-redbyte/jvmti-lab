# server

Локальный тестовый сервер VaultNotes на Ktor. Запускается на компьютере одной командой, эмулятор ходит на него по адресу `10.0.2.2`.

```bash
./scripts/run-server.sh
```

| Адрес | Что это |
|---|---|
| `https://0.0.0.0:8443` | основной API, самоподписанный сертификат |
| `http://0.0.0.0:8080` | тот же API без TLS, удобно смотреть через curl |

Пользователь: `demo`, пароль `demo`. Состояние живёт в памяти и сбрасывается при перезапуске. Флагов CTF на сервере нет: все они спрятаны в самом приложении.

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/auth/login` | `{"user","password"}` → `{"token","user","expiresIn"}` |
| `POST` | `/auth/logout` | завершает сессию |
| `GET`, `POST` | `/notes` | заметки пользователя |
| `POST` | `/payments` | «оплата» премиума: `{"card"}` → `{"status","card","last4","receiptId"}` |
| `GET` | `/premium/status` | есть ли у пользователя премиум |
| `POST` | `/analytics` | события встроенного SDK аналитики |

Запросы с `/notes`, `/payments` и `/premium/status` требуют заголовок `Authorization: Bearer <token>`.

## TLS

Сертификат создаётся при первом запуске в `server/certs/` и в git не попадает. Он самоподписанный, поэтому нормальный клиент такому серверу доверять не должен.
