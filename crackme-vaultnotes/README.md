# crackme-vaultnotes

> Хотите пройти VaultNotes сами? Не заглядывайте в `agents/`, `auditor/` и под спойлеры в `FLAGS.md`, пока не найдёте флаги своими инструментами.

Подопытное приложение **VaultNotes** (в статьях — HackMe): «защищённые» заметки с входом по PIN, поиском, премиум-подпиской и справкой во WebView.

> ⚠️ Приложение уязвимо нарочно. Его код показывает, как делать **не нужно**: не переносите его в настоящие проекты.

## Модули

| Модуль | Что внутри |
|---|---|
| [`app`](app) | экраны, сеть, премиум, WebView-справка; `src/main/cpp` — `libvault.so` |
| [`analytics-sdk`](analytics-sdk) | встроенный «сторонний» SDK аналитики |
| [`data`](data) | Room поверх SQLite: заметки, кэш ответов, сессия |

## Сборка

- `minSdk` 28: ниже нет `Debug.attachJvmtiAgent` и нормального ART TI.
- Сборка `debug` и отдельная обфусцированная сборка с R8 (minify + full mode), которая остаётся debuggable. Все агенты частей 2–4 работают против обфусцированной сборки.
- ABI: `x86_64` для эмулятора и `arm64-v8a` для устройства.
- Сервер по умолчанию: `https://10.0.2.2:8443` (эмулятор ходит на ноутбук).

Проект Gradle появится вместе с первой статьёй.
