# auditor

Итоговый аудитор цикла: агенты частей 2–4 в одной `.so`, правила в JSON и HTML-отчёт.

- [`rules`](rules) — правила: детекторы секретов, хуки на API, ожидаемое поведение.
- [`report`](report) — превращение JSON-отчёта агента в HTML.

В части 4 аудитор подключается к инструментальному тесту в CI: тест падает, если токен живёт после выхода, SDK трогает `ANDROID_ID` до согласия или появился новый динамически загруженный DEX.
